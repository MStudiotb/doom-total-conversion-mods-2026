## FAQ

**Are these standalone games or do I need DOOM?**  
Ashes 2063, Hedon, and Grezzo are standalone. Brutal DOOM and Project Brutality need a DOOM IWAD.

**Can I play Brutal DOOM in coop?**  
Yes — Brutal DOOM has full coop support. Use Zandronum as the multiplayer source port.
